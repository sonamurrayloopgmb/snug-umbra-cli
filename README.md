# snug-umbra-cli

Python · PostgreSQL

处理日常小任务的工具

## 用法

```bash
cat data.txt | cargo run
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/snug-umbra-cli.git
cd snug-umbra-cli
cargo build --release
```
